# Pincer 0.4.2 — исправлена сборка E2E тестов и проверка формы создания агента

Версия 0.4.2 — это техническое обновление для стабилизации процесса сборки. В предыдущей версии E2E-тесты в GitHub Actions аварийно прерывались по таймауту из-за жесткой задержки ответа локального сервера и неполного тестирования отключения кнопок при сохранении конфигураций агента.

## Что нового в 0.4.2

- Увеличено время ожидания (до 15 секунд) при загрузке стартовой страницы веб-интерфейса в Electron-сценариях E2E (`setup-page`).
- Добавлено явное ожидание отключения кнопки (`toBeDisabled`), а также скрытия всплывающих панелей после ввода информации о личности агента (`SOUL.md`) через форму. Это предотвращает зависание Playwright при ожидании завершения запросов.
- В тестах теперь корректно изолируются скриншоты для версии `0.4.2` (`chat-audit-0.4.2` и `settings-audit-0.4.2`).
- Обновлены версии в `package.json`, `package-lock.json` и `RELEASE_NOTES.md`, а также конфигурация GitHub Actions для выпуска релизов.

## Что изменилось

- Каталог API-моделей загружается автоматически после ввода адреса и ключа;
  сохраняются все полученные модели без подстановки заранее выбранной модели.
- Добавлено редактирование отображаемого имени существующего провайдера.
- В статистике чата показываются лимиты выбранной модели и соответствующих аккаунтов.
- Кнопка ожидающих разрешений расположена над вводом справа и исчезает после решения.
- Исправлены отступы статистики, вложенность команд, сетка памяти и геометрия поверхности чата.

- Все разделы настроек собраны в одном боковом меню и открываются внутри единой
  рабочей поверхности без повторяющихся заголовков и отдельных фоновых слоёв.
- Добавлены недостающие разделы: чат, горячие клавиши, навыки, лимиты
  провайдеров, расширенные параметры Gateway и полная схема OpenClaw.
- Настройки подключения разделены на понятные вкладки «Подключение» и
  «Параметры Gateway». Секреты продолжают храниться средствами операционной
  системы и не показываются после сохранения.
- Для лимитов провайдеров добавлена отдельная настройка адреса OmniRoute и
  management token с безопасным хранением. Переход к источникам лимитов теперь
  оформлен как явное действие, а добавление провайдера находится в заголовке.
- Заголовки, описания, карточки, поля, кнопки, выпадающие списки и вкладки
  приведены к одной системе размеров и отступов.
- Закреплена единая геометрия: элементы управления имеют скругление 8 px,
  панели и карточки — 12 px, внешняя рабочая поверхность — исходные 16 px,
  обводки — 1 px. Переключатели повторяют прямоугольную геометрию остальных
  элементов; круглая форма остаётся только у статуса и прогресса.
- Возвращены важные общие подложки чата и настроек, отделяющие рабочую область
  от боковых панелей. Вложенные страницы остаются прозрачными.
- Исправлено сохранение ширины рабочей области, её плавное открытие, закрытие и
  скрытие при перетягивании за допустимую границу.
- Курсоры ограничены тремя состояниями: обычная стрелка, ввод текста и изменение
  ширины панели.
- Новый чат появляется в списке только после отправки первого сообщения.
  Активный агент выбирается в верхнем меню, а состояние работающих чатов не
  пропадает при переключении.
- Исправлено создание чата из локального проекта: Pincer передаёт Gateway только
  рабочую папку и больше не совмещает несовместимые `projectId` и `cwd`.
- Переименование заголовка больше не задерживает переход: другой чат выбирается
  первым же нажатием, а новое название сохраняется в фоне.
- Возвращён боковой навигатор по связкам «вопрос — ответ» и уплотнён журнал
  команд: действия собраны в один раскрываемый блок.
- Уточнены этапы работы и таймеры: запуск модели, размышление и выполнение
  инструментов отображаются раздельно; время ответа больше не сбрасывается.
- Каждый чат сохраняет собственную модель; агент существующего чата больше не
  переключается случайно. Выбор Thinking скрыт у неподдерживающих его моделей,
  а уровень Gemini Pro Agent исправлен с Max на High.
- Список команд во время ответа остаётся компактным. Кнопка возврата вниз
  получила анимацию нажатия и прокручивает переписку до фактического конца.
- Вложения снова видны после отправки и перезагрузки истории. Pincer не вводит
  собственного ограничения на число файлов или 20 МБ и соблюдает только
  фактическую политику подключённого Gateway. Для полей ввода добавлено системное
  меню правой кнопки мыши с копированием и вставкой.
- Настройка API-провайдера принимает список моделей, сохраняет введённое имя и
  позволяет удалить провайдера через безопасную замену конфигурации Gateway.
- Иконка приложения, окна и Windows-установщика заменена на фирменную Pincer.
- Добавлен выбор поведения при закрытии окна: полное завершение или скрытие в
  системный трей. В меню значка трея можно быстро сменить режим, открыть Pincer
  или полностью выйти.
- Добавлено уведомление о сжатии контекста и исправлены цвета обновления для
  светлой и тёмной темы.
- Русская локализация расширена на настройки и вложенные страницы OpenClaw.
- Убрана скрытая загрузка полной схемы OpenClaw при каждом переходе: расширенные
  параметры запрашиваются только после раскрытия блока, а схема повторно
  используется в пределах текущего подключения.
- Переходы между настройками сокращены до лёгкого появления без сдвига текста.
  Загрузчики больше не заменяют страницу целиком, а изменение высоты данных не
  сдвигает заголовок и не меняет позицию прокрутки.
- Тяжёлый просмотрщик файлов вынесен из стартовой загрузки: основной интерфейс
  открывается быстрее, а код рабочей области загружается только при её показе.

## Проверка и выпуск

- Модульные, интеграционные и Electron-сценарии запускаются автоматически.
- GitHub Actions проверяет версию тега, выполняет тесты и собирает Windows
  installer для релиза `v0.4.2`.
- Для установки используется файл `Pincer-Setup-0.4.2-x64.exe`. До добавления
  сертификата Windows может показать предупреждение о неизвестном издателе.
